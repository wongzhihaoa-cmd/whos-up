Animals

Each class keeps its own collection across lessons. Common animals come first. The longer the class stays calm without a scare, the better the chance of uncommon and rare ones. Several of the same animal can be out at once.

Test animals don't count toward the collection.

Paste a full class list (one box, split into groups for me)

One name per line, e.g. copied from a spreadsheet or class register. Numbers at the start of a line (1. or 2)) are ignored. This replaces everyone in this class and deals them randomly into the groups above. Ability (optional): add a score after a comma or tab, e.g. Tan Wei, 78, and each group gets a mix of strong and weaker students. Scores are used only for splitting, never shown, and the Shuffle button keeps using them.

Picked so far

Click a name to put it back in its group.

Backup and restore

Your classes are saved in this browser only. Back them up so a cleared browser or a new computer doesn't mean retyping every list. Backups hold class names, groups and names. Screenshots are not included.

Restoring adds the backed-up classes next to the ones you have. It never overwrites anything.

Delete this class

Removes the class, its groups, its text and its screenshots from this browser.
